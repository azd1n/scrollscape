Scrollscape web app (installable on Android)

1. Upload this whole folder to any static host (Netlify Drop, Cloudflare Pages, GitHub Pages, etc.). The page must be served over https.
2. Open the address in Chrome on your Android phone.
3. Chrome menu (three dots) > "Install app" or "Add to Home screen".
4. It opens full screen with its own icon and works offline after the first visit.

Playing with friends is not available in this version. Solo play works fully.
